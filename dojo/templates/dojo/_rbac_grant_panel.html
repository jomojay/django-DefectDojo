{% load i18n %} {% load get_attribute %} {% comment %} Shared RBAC grant panel (INTEGRATIONS_ROADMAP.md §7.8). One partial covers all four combinations - product x member, product x group, product type x member, product type x group - because the only things that vary are the label copy, the queryset, and which URL names the row actions post to. Four near-identical 40-line blocks was the alternative; this is the one place the roadmap calls out a shared partial as clearly worth its cost. Caller must NOT include this while DD_FEATURE_RBAC is "off": the callers gate on the feature_rbac_enabled tag (dojo/templatetags/authorization_tags.py) and the views return no grant context at all in that state.
